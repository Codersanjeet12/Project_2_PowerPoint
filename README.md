# Python Calculator using Tkinter

## 📌 Project Overview
This project is a **Basic Calculator GUI** built with Python’s Tkinter library.  
It allows users to perform core mathematical operations with a simple and user‑friendly interface.

## ⚙️ Features
- Equation display area (screen)  
- Clickable buttons for digits and operators (+, -, *, /)  
- Evaluate expressions (=)  
- Clear screen (C)  
- Error handling for invalid inputs
